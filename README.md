# 🚀 REACT NATIVE - HARCAMA TAKİBİ UYGULAMASI 🚀
Bu proje, kullanıcıların kolay bir şekilde harcamalarını yönetebilmeleri için tasarlanmıştır. TypeScript ve React Native kullanarak sıfırdan geliştirdim.

* **✅ Yeni Harcama Ekleme:** Basit arayüzle hızlıca yeni harcama kayıtlarınızı oluşturun.
* **🗑️ Harcama Silme:** İhtiyacınız olmayan ve gereksiz harcamalarınızı, harcama listenizden kolayca kaldırın.
* **✏️ Harcama Düzenleme:** Var olan harcamalarınızı anında güncelleyin.
* **🔎 Harcama Arama ve Filtreleme:** Arama çubuğunu veya filtre butonunu kullanarak harcamalarınız arasında ister harcama ismine göre, ister tarihe göre, istersenizde kategorilere göre anında arama yapın ve ilgili harcamalarınızı hızlıca bulun.
* **💰 Tüm Harcamalarınız Tek Ekranda:** Uygulamaya eklemiş olduğunuz tüm harcamalar tek ekranda.
* **📊 Harcama Grafiğinizi Görmek:** Hangi kategoride ne kadar harcama yaptığınızı gösteren tablo sayesinde hangi kategoride daha fazla veya daha az harcama yaptığınızı görebilirsiniz.
  
## ⚙️ Kurulum ve Çalıştırma
Uygulamayı yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:

1.  **Gereksinimler:**
    * Bilgisayarınızda **Node.js**'in kurulu olması gerekmektedir.

2.  **Bağımlılıkları Yükleme:**
    VS Code terminalini (veya tercih ettiğiniz bir terminali) açın ve gerekli paketleri indirmek için aşağıdaki komutu çalıştırın:
    ```bash
    npm install
    ```

3.  **Uygulamayı Başlatma:**
    Paketler yüklendikten sonra, uygulamayı başlatmak için terminalde şu komutu kullanın:
    ```bash
    npx expo
    ```
    Bu komutu çalıştırdıktan sonra ister telefonunuzda istersenizde emülatörden uygulamayı çalıştırabilirsiniz.

Artık uygulamayı kullanmaya hazırsınız!
